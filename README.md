# Flow / GanChart

輕量、離線可用的多專案甘特圖。純 HTML / CSS / JavaScript，無 CDN、無執行期套件、無帳號與後端。

## 開啟

雙擊 index.html，使用現代 Edge / Chrome 即可。應用程式的 HTML、CSS 與 JavaScript 已全部合併在這一個檔案，複製或攜帶時只需要 index.html；不需要其他程式檔。

若瀏覽器限制 file:// 的儲存或檔案 API，可使用 Python 3 執行 python serve.py，開啟 http://127.0.0.1:8765 。它只監聽本機介面。不同網址與直接開啟 HTML 使用不同瀏覽器儲存區，請用 JSON 搬移資料。

## 功能

- 每個專案獨立網址、群組與任務；專案、群組、任務拖曳排序，任務可跨群組。
- 多專案總覽：每個專案的摘要期間與里程碑，點名稱進入專案。
- 日、週、旬、月、季與縮放；範圍由任務日期及正在顯示的基準推算，空白專案沒有預設日期。
- 開始與結束留空＝未排程；只填開始＝里程碑；起訖皆填＝含起訖日的期間。
- 未排程區可直接編輯日期；已有時間軸後，可拖入時間軸排定日期。
- 群組收合將全部子任務壓成同一列。重疊色條可展開後分別查看。
- 色條拖曳平移，兩端可調整起訖；點名稱或雙擊色條編輯。
- 負責人、每日投入時數、狀態、進度、色塊、備註、搜尋與篩選。
- 多選後批次平移日期、變更負責人、狀態、進度、色彩、群組或刪除。
- 相依為 finish-to-start（前置完成後開始），支援多前置與跨群組；拒絕循環與無效連結，展開時顯示連線。
- 相依可自動連鎖順延或只提示衝突；自動順延只向後、不提早，也不自動排定未排程任務。
- 自訂每週工作日、假日與每日容量；工作天模式的平移會排除非工作日。日視圖以陰影顯示休息日。
- 保存基準計畫，灰線比較原訂日期，任務下方顯示完工差異（日曆天）。可覆寫基準並復原。
- 負責人工作量：跨專案依週彙總投入與容量，提示單日超載；滑鼠停留查看每日任務。完成與暫停任務不計入。
- 複製群組、複製專案並指定新起點、儲存與套用範本；複製專案重設進度與基準，保留前置關係。
- 最近 60 次操作復原 / 重做，Ctrl+Z / Ctrl+Shift+Z；重新整理不保留操作歷史。

## 時間代碼

週日到週六為一週，含 1/1 的週為該年第一週，跨年在 1/1 分段重新編號。

| 日期 | 週次 |
| --- | --- |
| 2026/1/1–1/3 | W601 |
| 2026/1/4–1/10 | W602 |
| 2026/12/27–12/31 | W653 |
| 2027/1/1–1/2 | W701 |
| 2027/1/3–1/9 | W702 |

旬表頭上層以月份合併（例如 M611），下層 B＝1–10、M＝11–20、E＝21–月底。月為 M601–M612，2027 為 M701–M712；季為 Q61–Q64。年碼使用年份個位數，完整年份在表頭或滑鼠提示中。表頭不顯示起訖日期，滑鼠停留可查看。

## 儲存與匯出

1. 自動保存於目前瀏覽器 localStorage，沿用舊版儲存鍵並自動升級資料格式。清除瀏覽資料、改瀏覽器或搬動檔案前，請匯出 JSON。
2. 「連結 / 另存本機檔案」：選擇 JSON 後，本次開啟期間的變更會依序同步寫入。重新開啟頁面後，請再按「開啟本機檔案」以恢復連結。檔案 API 不支援時改用下載 / 上傳。
3. 「開啟本機檔案」取代目前工作區，可復原；「合併匯入」新增副本，重新產生 ID，不覆蓋現有資料，保留目前工作日設定。
4. JSON 備份包含專案、範本、基準與工作日設定。未備份或超過 7 天會提醒。
5. Excel 匯出為真正 .xlsx，含完整任務清單、前置任務、基準與差異、每日工作量、工作日設定。專案頁匯出該專案，總覽／工作量頁匯出全部專案；搜尋不裁切 Excel 明細。
6. PNG 匯出目前圖表，保留收合與篩選結果；過大圖表會提示縮小或改月／季尺度。
7. PDF 使用「列印 / PDF」後選擇「另存為 PDF」。建議橫向並調整縮放；長排程可先切換月／季。這是瀏覽器列印流程，沒有內建 PDF 引擎。

請避免多分頁／多裝置同時編輯同一檔案；沒有雲端同步、檔案鎖或多人即時協作。容量目前採每人共用每日時數，可在工作日設定調整。假日由使用者維護，不會自動下載。日期支援 1900–2199，過長時間軸會自動切換較粗尺度。

## 開發與驗證

Node.js 18+ 執行 node tests.cjs；不需 npm install。測試涵蓋資料升級、跨年與閏年、工作日與假日、相依循環／順延、基準、複製 ID、批次表單、檔案寫入順序與失敗處理、Excel 封裝及應用程式資料流程。DOM stub 測試不能取代真實瀏覽器操作驗證。

- index.html：完整工具。內含樣式，以及以 data-flow-source 標示的 core（日期與排程）、exports（Excel／PNG 匯出）、app（介面與儲存）區段；直接在同一檔案維護。
- tests.cjs：從 index.html 讀取內嵌程式，執行核心與應用整合檢查；使用工具時不需要此檔。
- serve.py：選用的本機預覽伺服器；直接開啟 HTML 時不需要。
- backup-before-v2/：本機保留舊版來源，已排除 Git。

本次環境的瀏覽器驗證因工具無法判定 Windows 瀏覽器網址而中止；已進行的程式檢查與真實 UI 驗證應分開看待。
